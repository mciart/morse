# 摩斯输入（MorseWriter）

用一到三个按键输入摩斯码，完成文字输入、键盘快捷键和鼠标操作。本项目基于 [MorseWriter](https://github.com/willwade/MorseWriter) 改进，提供简体中文界面，主要面向 Windows。

[英文码表](codechart.md) · [拼音码表](docs/pinyin-code-chart.md) · [问题反馈](https://github.com/mciart/morse/issues)

## 功能

- 统一的虚拟键盘与鼠标引导：按键按美式键盘位置排列，默认自动适应窗口。鼠标对照默认隐藏，可随时开启，日常使用无需切页。
- 统一采用国际摩斯优先的编码，补齐常用标点及反引号。
- 拼音层沿用 37 个注音电码，左侧声母、右侧韵母；默认按住 F22 使用，也可设为单击切换，两种方式均支持双击显示／隐藏码表。
- 可选与当前输入窗口的微软拼音中／英文状态双向同步；拼音码表包含常用符号，输入中文时无需为标点切回英文码表。
- 可切换精简叠加层：窗口收紧到键位区域，无标题栏和外围空白，只有按键保留背景；支持拖动边缘调整大小，显示码表时不抢走目标应用焦点。
- 默认跟随系统切换深色与浅色外观，Windows 原生标题栏同步切换；也可在设置中固定主题，立即应用并保存。
- 支持单键直键、双键和三键手动输入，以及可选的自动电键；点划速度、字符确认间隔和音高、音量均可调整。
- 可选 F13–F24 与 Windows 鼠标 X1 / X2 作为输入键，方便通过 reWASD 使用手柄输入。
- 按下状态、当前点划、确认进度与输入结果即时显示；点划声音采用连续合成及渐入渐出。
- 支持单次组合键、修饰键锁定，以及鼠标移动、点击、双击和拖动。
- 最小化按钮收到任务栏，× 收到系统托盘并继续输入；通过托盘暂停、恢复或退出。
- 支持开机自启到托盘，以及可修改的全局码表快捷键，可直接选择 F22 等功能键。

拼音层输出拼音字母，由当前系统拼音输入法显示候选并选字。软件不自带中文候选系统；微软拼音状态同步默认关闭，开启后同步当前微软拼音的中／英模式，不会替你更换系统输入法。

## 快速开始

Windows 10 / 11 的 64 位用户可直接下载 [最新版安装包](https://github.com/mciart/morse/releases/latest)，运行 `MorseWriter-Setup-v版本号-x64.exe`。安装向导为简体中文，无需另装 Python，默认安装到当前用户目录；首次启动的界面主题跟随系统。

需要从源码运行时，安装 Python 3 和 Git，在 PowerShell 中执行：


```powershell
git clone https://github.com/mciart/morse.git
cd morse
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe MorseCodeGUI.py
```

已克隆项目时，从项目目录内创建虚拟环境即可。后续启动只需执行最后一行命令。

1. 打开要输入的应用，首次练习建议使用记事本。
2. 在软件中选择按键数量及对应输入键。想使用接近 morsey 的双键操作，可点击“标准电键预设”：自动电键、15 WPM、600 Hz；输入键保持原选择。
3. 点击“开始输入”，将焦点切回目标应用，再输入摩斯码。
4. 先练习 `E（•）` 和 `T（—）`，再参照面板输入其他按键。

当前模式选定的输入键用于摩斯输入，拼音层按键另外处理切层与码表显隐；其他按键和数字小键盘可照常使用。选择 `1`、`2` 时，对应字母上方的数字键。输入过程中，选定的点划键会被程序拦截；返回设置或暂停后恢复通常用途。

## 使用说明

### 输入模式

`•` 表示点，`—` 表示划。

| 模式 | 点与划 | 完成一个字符 |
| --- | --- | --- |
| 单键直键 | 按下立即发声，松开停止；短按输入点，长按输入划 | 松开后等待“字符确认间隔” |
| 双键手动 | 第一个键每次按下输入一个点，第二个键每次按下输入一个划；支持按键重叠 | 松开所有输入键、点划声音结束后等待确认 |
| 三键手动 | 前两个键与双键手动相同 | 按第三个键立即完成，并结束当前声音 |

双键或三键模式可开启“自动电键（长按连发、双键交替）”：按住点键或划键会按标准节奏连发，同时按住两键会交替发点和划。短暂按下另一个键也会被记住，在当前点划结束后接续。三键模式仍由第三键确认。

默认速度为 **15 WPM**，一点为 80 毫秒，一划为 240 毫秒，码内间隔为 80 毫秒。这里 WPM 用于控制点划节奏，实际输入速度还取决于所用功能码及确认间隔。

- 默认按速度使用标准时长。需要增加容错时，展开“高级：自定义识别时长”；单键模式显示点划分界，单键、双键显示字符确认间隔，三键直接由第三键确认。
- “单键点划分界”为 `0` 时取两个点的时长；“字符确认间隔”为 `0` 时取三个点的时长。15 WPM 时分别为 160 和 240 毫秒。自定义字符间隔不会短于标准间隔。
- 旧配置中的固定时长会保留；关闭高级选项即可恢复标准时长。旧版“快速摩斯模式”开启的配置会迁移为自动电键。
- 程序不会因停顿自动输入空格。需要空格时，请输入码表中的 `Space` 编码，避免在游戏或其他应用中意外触发空格动作。

### 拼音输入

先在目标应用中启用系统拼音输入法，再开始摩斯输入。设置中的 **“拼音与码表切换”** 独立区域直接显示“按住使用”和“单击切换”两个选项，选择后点击该区域的“应用”。默认操作按键为 **F22**，可改为其他单个功能键（F1–F24，F12 除外），不能与点、划或确认键重复。

| 方式 | 切换拼音层 | 显示／隐藏码表 |
| --- | --- | --- |
| 按住使用（默认） | 按住进入拼音层，松开恢复英文键盘 | 快速双击同一个键，不改变当前层 |
| 单击切换 | 单击切换拼音／英文，松开后保留当前层 | 快速双击同一个键，不改变当前层 |

按住方式在持续按下约 180 毫秒后进入拼音层；如果已经开始输入点划，会立即确认按住，无需等满时长。快速双击的短按不会短暂切入拼音，因此也不会让同步的微软拼音来回切换。单击切换会短暂等待以区分双击；开始输入点划时会立即确认单击。已经开始的电码以第一个点划确定所属层，中途松开或切层不会改变这次电码的解释。

拼音码表左侧显示声母，右侧显示韵母，下方显示符号、数字、选字和编辑键；完整模式和精简模式都能切换。37 个基础符号沿用注音原码，键帽直接显示拼音，例如 `ㄚ（———）` 输入 `a`，`ㄓ（••••）` 一次输入 `zh`，`ㄤ（——•）` 一次输入 `ang`。依次输入 `zh` 和 `ang` 得到 `zhang`，再用系统输入法选字。

补充的 `ing`、`uang`、`iu`、`ui` 等完整韵母使用软件扩展码，一次输入完整拼写，避免将 `i + eng` 误拼成 `ieng`；`y / w` 用于 `ying / wu` 等零声母拼写。按输入法键盘约定，`ü` 输出 `v`，`üe` 输出 `ve`，`ê` 输出 `e`：例如 `l + üe → lve`，`j + ue → jue`。不会自动改写已经输入的音节。

Space、Enter、Esc、End、Insert 的英文码与注音码冲突，因此在拼音层使用不同编码；英文层保持原码。鼠标区仍可独立开启，31 个鼠标动作保持原码。全部键位与实际输出见 [拼音码表](docs/pinyin-code-chart.md)。

拼音层包含 **26 个符号**，其中 19 个沿用英文层的编码；`?`、`(`、`/`、`#`、`&`、`+`、`=` 与拼音码冲突，改用独立扩展码。符号按键会送给当前输入法，最终显示中文标点还是英文标点，由输入法自身的标点模式决定。

### 同步微软拼音

在“拼音与码表切换”中勾选 **“与微软拼音中／英文状态双向同步”**，点击“应用”或“保存设置”。此选项默认关闭，开始输入后生效，作用于当前正在输入的窗口：

- 微软拼音切到“中”，码表同步显示拼音层；切到“英”，码表同步显示英文层。
- 用操作按键切换码表时，微软拼音同步切到对应模式。按住方式进入拼音时切中文、松开后回英文；单击切换方式保留所选模式。
- 快速双击只显示／隐藏码表，不改变输入层或微软拼音状态。

切回英文时，如果最后一段电码还在等待确认，软件会先在原输入法模式下完成它，再切换。微软拼音中尚未选字的内容会保留为原拼音字母：例如输入 `nihao` 后单击 F22 切回英文，或在“按住使用”时松开 F22，输入框中保留 `nihao`，不自动选择“你好”。需要中文时，在切回英文前用数字或 Space 选字。

同步使用原生输入法接口，不额外发送 Enter、Space 或 Shift。切换前确认目标窗口和微软拼音身份，切换后读取实际状态；结果未确认时会提示失败。窗口已改变、访问权限不足、输入法响应超时等情况会分别提示原因。切到其他窗口后，旧请求不会写入新窗口；无法读取的状态不会被当作英文。同步不会替你更换系统输入法，身份无法确定时不会执行切换。关闭同步后仍可手动切层，配合其他拼音输入法使用。

### 手柄与冷门输入键

推荐将两个输入键设为 **F23 / F24**；设置也提供完整的 F13–F24。它们是独立的键盘键，便于减少与常用快捷键的冲突。reWASD 支持将这些键映射到手柄按键。[reWASD 功能键说明](https://www.rewasd.com/blog/post/how-to-change-function-keys-windows-10)

1. 在 reWASD 中，将两个手柄按键分别映射到 F23 和 F24；本软件中选择“双键”，对应选择 F23 和 F24。
2. 使用普通按下／松开映射，保留按住时长；关闭该映射的连发、切换保持或定长按键宏，由本软件处理点划节奏。
3. 对被映射的原始手柄按键启用 **Mute（屏蔽原始输入）** 并应用配置，避免游戏同时收到原手柄动作。[reWASD Mute 说明](https://help.rewasd.com/mapping-features/unmaps.html)
4. 先在记事本验证点、划和长按行为，再在目标游戏中检查是否有重复动作或输入冲突。

需要拼音切层时，可再把一个手柄按键映射为 F22，配合 F23 / F24 输入点划；使用“按住使用”时仍需保留正常按下／松开事件。

Windows 下也可选择“鼠标 X1（侧键）”和“鼠标 X2（侧键）”，并将 reWASD 对应映射为这两个鼠标按键。只有选中的侧键会用于摩斯输入，其他鼠标操作保持可用；X1 / X2 可能原本用于前进、后退或游戏功能，因此仍需检查目标应用的绑定。

**鼠标侧键输入与鼠标码表开关相互独立。** 码表默认关闭鼠标区域，也能使用 X1 / X2 输入摩斯码；开启鼠标区域只是显示通过摩斯码执行鼠标动作的对照。

### 声音与反馈

点和划使用相同音高，以时长区分，默认 **600 Hz、音量 30%**；可在设置中调整和试听，通过“音频设备”选择输出。声音由连续合成器生成，边缘带渐入渐出；输入期间无需逐次加载音效文件。输入时需勾选“播放摩斯音”；试听可以在静音状态下单独使用。

单键直键的声音跟随按下和松开；双键手动模式每次按下立即记入符号，点划声音依次播放；自动电键按标准点划节奏播放。字符完成和无效码的额外提示音默认关闭，可独立开启，其播放不会替换点划声。

音频由独立线程持续输出，点划边沿按输入时间戳保留，即使界面短暂忙碌、按下和松开一同送达，也不会将首个短音合并成静音。自动电键的点划比例、码内间隔、对侧按键记忆与 morsey 对齐；本项目仍使用 Qt 音频后端，设备延迟与 morsey 的原生音频实现可能不同。

码表上方显示按键状态、正在发出的点或划、当前编码及确认进度。完成后短暂保留输入结果或“无效码”，下一次输入可以立即开始。

### 键盘与鼠标引导

默认面板按键盘和鼠标布局展示编码，输入过程中会提示仍可匹配的动作。按键名称沿用美式键盘标识。

编码优先使用国际摩斯：A–Z、0–9 及已有国际定义的标点采用 [ITU-R M.1677-1](https://www.itu.int/dms_pubrec/itu-r/rec/m/R-REC-M.1677-1-200910-I!!PDF-E.pdf) 编码，`!`、`&`、`;`、`_`、`$` 使用常见扩展。共包含 54 个字符，其中 53 个与 Morsey 的字符表一致，并补齐美元符号 `$`（`•••—••—`）。这些常见扩展不属于 ITU 正式定义。

与旧版相比，15 个标点的编码发生变化；为避免冲突，F9、Delete、Tab、星号、百分号和修饰键锁定使用独立的七位扩展码。反引号（\`）补充为七个点 `•••••••`，显示在美式键盘数字行最左侧。反引号、控制键和鼠标动作均为软件扩展；鼠标继续使用以划开头的七位码。

英文键盘只保留统一编码方案，旧版专用方案和分页布局已移除；拼音层通过专用按键切换。升级时自动整理已有布局；输入键、声音、主题和位置偏好继续保留。请以当前面板和 [英文码表](codechart.md) 为准，旧标点编码不再作为别名，避免输入标准斜杠时误触 Delete 等动作。

“适应窗口”会缩放码表，使所有已显示的组件都落在窗口内；关闭后可滚动查看。需要鼠标引导时开启“鼠标”开关。这两个选项也可在设置中修改，并自动保存。

切换显示器、调整分辨率或 Windows 显示缩放后，码表会自动重新计算文字尺寸与键位布局，无需重启。已隐藏或最小化的窗口会保持原状态，刷新不会将其弹出。

设置统一使用虚拟键盘面板，已移除旧版码表选择、固定位置坐标、字母大小写显示和无效的调试选项。窗口可直接拖动，关闭“码表自动适应窗口”后才显示手动缩放。

设置窗口首次打开会按当前屏幕可用区域确定大小。缩窄窗口时，选项会换行，内容只需纵向滚动，底部“音频设备”“保存设置”“开始输入”按钮保持可见。切换显示器或调整显示缩放后会重新适应可见区域，正常范围内的手动窗口大小不会被覆盖。

完整码表和精简码表分别记住最后的位置，返回设置后重新开始输入、隐藏码表或退出重启都会保留。显示器被移除或位置不再可见时，窗口会移回可见屏幕；隐藏或最小化时不会因此弹出。

已移除英文词语候选、后台预测和旧打字页的缩写展开，统一面板直接输出对应按键。

### 精简叠加层与游戏

在码表顶部勾选“精简显示”，窗口本身会收紧到键位板大小，仅保留按键及按键内的文字和摩斯码；已开启的鼠标对照也会保留。标题栏、输入反馈条、状态栏以及“键盘”“符号”“导航”等按键外的文字全部隐藏，按键之间的空隙透明。

按住键位区域内部拖动可移动窗口；将鼠标移到四条边或角落，出现缩放光标后拖动，可等比例调整大小。也可右键打开“调整大小”，选择“放大”“缩小”或“默认大小”。调整后的比例会自动保存，重新打开精简模式时继续使用；窗口会限制在屏幕内。右键菜单可恢复完整显示及此前的完整窗口大小，托盘和设置中也可切换。

精简模式会保留手动设置的缩放比例。切换到较小的屏幕时，码表会临时缩小以完整显示；回到有足够空间的屏幕后，继续使用保存的比例。

完整和精简码表都保持置顶，显示、拖动、缩放和打开码表菜单时不会主动激活码表窗口，减少操作码表时目标应用失去焦点的问题。普通窗口和无边框全屏游戏通常可以显示叠加层；独占全屏游戏可能绕过桌面窗口合成，普通置顶窗口不能保证覆盖。需要游戏内查看时，优先在游戏中选择无边框全屏或窗口模式。[微软全屏模式说明](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/)

### 组合键

- 单次操作：先输入 `Ctrl`，再输入 `V`，执行一次 `Ctrl+V` 后自动释放 `Ctrl`。`Shift`、`Alt` 和 `Windows` 键的用法相同。
- 连续操作：先开启“修饰键锁定”，再输入 `Ctrl` 和其他按键；再次输入“修饰键锁定”会关闭锁定并释放修饰键。它不会自动重复上一项操作。
- “左向 Tab”执行 `Shift+Tab`；“开始菜单”打开系统开始菜单；“应用菜单”打开当前项目的上下文菜单。

### 窗口与托盘

- 点击最小化按钮：窗口缩到任务栏，继续接收摩斯输入。
- 点击 ×：隐藏到系统托盘，继续接收摩斯输入；不占用任务栏窗口按钮。Windows 决定托盘图标直接显示在右下角，还是收在“显示隐藏的图标”箭头中。
- 点击托盘图标或选择“显示窗口”：恢复窗口。
- 托盘菜单的“启用输入”带勾表示正在接收输入；取消勾选即暂停并释放程序按住的修饰键，再次勾选则继续。尚未开始输入时，勾选可按当前设置开始。
- “打开设置”或面板上的“返回设置”：停止输入并修改配置。
- “退出”：关闭程序并释放键盘监听及修饰键。

### 开机自启与快捷键

- 在“启动与快捷键”中勾选“开机自启，并收进系统托盘”，登录 Windows 后程序会自动运行，设置和码表都不会弹出。此选项立即生效，取消勾选即可关闭自启。
- 如需开机后直接接收摩斯输入，再勾选“启动后自动开始输入”并保存；否则程序只驻留托盘，等待手动开启输入。
- 在“拼音与码表切换”中设置拼音层按键，默认 **F22**，可选择“按住使用”或“单击切换”。两种方式都用双击显示／隐藏码表，隐藏时继续输入。取消“启用拼音层按键”可关闭这组手势。
- 原来的 **Ctrl+Alt+Shift+M** 作为额外的显示／隐藏快捷键保留；尚未开始输入时切换设置窗口。可选择 F13–F24 功能键，或选择“自定义组合键”后录入，再点击“应用”；也可关闭。若它与拼音层按键相同，例如都设为 F22，则统一由拼音层手势处理，避免第一次按下就触发显隐。快捷键不能与摩斯输入键重复，与其他软件冲突时会显示失败原因。
- 安装时也可选择开机自启，它与软件中的选项共用同一项 Windows 设置。卸载时移除自启，保留个人配置。

安装版配置位于 `%LOCALAPPDATA%\MorseWriter\user_data`，与程序目录分离，升级不会覆盖已有偏好。新用户默认跟随系统主题。源码版仍使用项目的 `user_data`。升级不删除旧版已经保存的个人文件，但程序不再使用预测词库。

## 开发

主要模块：

| 文件 | 职责 |
| --- | --- |
| `MorseCodeGUI.py` | 设置、配置迁移、窗口及输入输出协调 |
| `morse_engine.py` | 使用单调时间的纯 Python 点划状态机、按键记忆及字符确认 |
| `input_listener.py` | 选定键的监听与拦截、带时间戳的事件、Windows X1 / X2 原生监听 |
| `windows_integration.py` | 当前用户开机自启、原生全局快捷键、置顶及不激活窗口的恢复 |
| `app_paths.py` | 打包资源定位、首次启动配置及旧配置迁移 |
| `tone_audio.py` | 连续音频合成、渐入渐出、输出设备及音频对象生命周期 |
| `virtual_keyboard.py`、`ui_theme.py` | 虚拟码表、反馈、自动缩放和系统主题／原生标题栏 |
| `keyboard_output.py` | 键盘动作、精确文字输出及修饰键状态 |
| `morse_profiles.py` | 国际优先与旧版编码方案、标点和控制键冲突处理 |
| `pinyin_codes.py` | 注音原码、拼音片段和扩展韵母、拼音层控制码冲突处理 |
| `guide_gesture.py` | 拼音层单键监听、按住／单击切层及双击显隐 |
| `windows_ime.py`、`ime_sync.py` | 前台微软拼音识别、目标绑定的状态读写及后台同步 |
| `crash_diagnostics.py` | 按进程保存运行日志、异常堆栈及 Qt 消息 |

软件引导与文档共用 `user_data/layouts.json` 的原始布局，以及 `morse_profiles.py` 中的编码方案转换；拼音层共用 `pinyin_codes.py` 的生成函数。同一工具生成并校验英文、拼音两份码表。修改映射后生成文档，并运行检查与测试：

```powershell
.\.venv\Scripts\python.exe tools/generate_codechart.py
.\.venv\Scripts\python.exe tools/generate_codechart.py --check
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
Remove-Item Env:QT_QPA_PLATFORM
```

测试通过虚拟时间验证重叠按键、点划比例、双键交替、确认及暂停行为；系统钩子、键鼠输出与音频设备使用模拟对象，界面测试使用离屏模式。音频波形及对象清理也有独立回归检查。测试不会安装真实系统钩子或向其他应用发送输入；实际延迟、设备兼容性及游戏输入仍需在对应环境中验证。

微软拼音的只读探针与自有窗口验证方法见 [开发与构建](docs/development-guide.md)。自动化测试覆盖输入法身份不明确、读取失败、目标窗口变化、双击和未确认电码的同步时序；原生验证不替代各个应用和游戏的兼容性检查。

### 诊断日志

从源码启动时，诊断文件位于 `user_data/logs`：`morsewriter-<进程编号>.log` 记录带时间的运行事件，`crash-<进程编号>.log` 保存能够捕获的崩溃堆栈。不同进程分开记录，启动不会清空上一进程的日志；运行日志达到大小限制后轮转。

如果再次遇到“内存不能为 read”、闪退或音频异常，请保留对应日志，并记录发生时间、当时操作、输入模式与音频设备。当前已改进原生回调和窗口／音频对象的退出清理；原生崩溃仍需结合实际日志定位，测试通过不能证明所有设备与环境中的崩溃都已解决。

打包 Windows 程序：

```powershell
.\build.ps1 -BootstrapCompiler
.\tools\check_frozen_build.ps1
```

构建脚本运行回归检查、校验资源清单、生成程序和中文 Inno Setup 安装包。`-BootstrapCompiler` 会将固定版本的官方编译器解包到项目 `build/tools`，不安装全局编译器；也可用 `-Iscc` 指定已有编译器。

构建结果及 SHA256 校验文件位于 `dist`。安装包不包含开发者配置、日志或个人学习数据。发布工作流在版本标签对应提交上重新验证、构建和检查安装内容，再发布 GitHub Release；不依赖外部组织的签名服务器。当前安装包未进行代码签名。

问题反馈和改进建议请提交到 [本仓库](https://github.com/mciart/morse)。
