# 安装与使用

适用于 Windows 10 / 11 x64。从 [版本发布页](https://github.com/mciart/morse/releases/latest) 下载 `MorseWriter-Setup-v版本号-x64.exe`，按中文向导安装，无需另装 Python。程序默认安装到当前用户目录，配置保存在 `%LOCALAPPDATA%\MorseWriter\user_data`，升级保留偏好。

从浏览器下载的安装包尚未代码签名。Windows 可能显示“无法验证发布者”或 SmartScreen 拦截，这不表示文件被篡改。可打开“更多信息”后选择“仍要运行”，再用发布页中的 `SHA256SUMS` 核对下载文件。安装完成后若勾选运行，请在系统托盘（任务栏右下角，必要时点击 ^ 显示隐藏图标）查找摩斯输入。

1. 打开设置，选择一到三个输入键。双键模式第一个键输入点，第二个键输入划；三键模式用第三个键确认字符。
2. 使用手柄映射时可选 F23 / F24，鼠标侧键可选 X1 / X2。点击“标准电键预设”可体验双键长按连发、15 WPM 的标准节奏。
3. 点击“开始输入”，切回目标应用。先在记事本练习 `E（•）` 与 `T（—）`。

统一码表包含 A–Z、0–9 和 18 个常用标点，国际电码已有定义的优先使用；其余标点采用常见扩展。反引号（\`）另用七个点 `•••••••`，位于数字行最左侧。旧版方案和分页布局已移除，升级后请留意标点及 F9、Delete、Tab、星号、百分号、修饰键锁定的编码变化，见 [完整码表](../codechart.md)。现有输入键、声音、主题和位置设置保留。

选定的点划输入键会被拦截；通过托盘取消“启用输入”即可暂停并恢复它们的普通用途。码表的“返回设置”也会停止输入。暂停、返回设置或退出时，会释放程序按住的修饰键和通过摩斯码按住的鼠标键，避免拖动状态残留。拼音层单键另用于切层和码表显隐。

源码运行沿用项目内的 `user_data/config.json`。仓库自带的旧配置为三键（1、2、Space）且静音，首次从源码启动也会使用这些值；与全新安装版的默认配置不同。需要声音时，在设置中勾选“播放摩斯音”。

## 输入拼音

先在目标应用中选择系统拼音输入法。设置的 **“拼音与码表切换”** 区域提供“双击切换”和“按住使用”，选择后点击“应用”。默认操作按键为 **F22**，可改为其他单个功能键（F1–F24，F12 除外），不能与点、划、确认键重复。

- **双击切换（新用户默认）**：单击 F22 显示／隐藏码表，快速双击切换中英文层一次并保留。单击最多等待 300 毫秒以区分双击；等待期间开始输入点划，会立即确认显隐，点划仍按当前层输入。双击保持码表原有显隐状态，长按不触发操作。
- **按住使用**：按住约 180 毫秒后进入拼音层，松开恢复英文；按住期间开始输入点划会立即确认。快速双击只显示／隐藏码表，不切层。

升级时，原“单击切换”设置改用新的双击切层、单击显隐手势；已选“按住使用”的用户保留原操作方式。

声母显示在左侧、韵母在右侧。37 个注音电码直接输出相应拼音；复合韵母 `ing`、`uang` 等有独立扩展码，一次输出完整拼写。例如 `zh + ang → zhang`，再由系统输入法选字。`ü` 输出 `v`、`üe` 输出 `ve`、`ê` 输出 `e`；软件不自带中文候选系统。

Space、Enter、Esc、End、Insert 在拼音层使用不同编码，鼠标动作仍保留原码。请查看 [拼音码表](pinyin-code-chart.md)。

拼音层下方还提供 26 个符号，19 个沿用英文层编码，7 个因与拼音冲突而使用扩展码。它们按普通键盘符号输入，最终使用中文或英文标点取决于系统输入法的标点模式。

## 同步微软拼音

在“拼音与码表切换”中勾选 **“与微软拼音中／英文状态双向同步”**，再点击“应用”。默认关闭；开启并开始输入后：

- 当前窗口的微软拼音为“中”时显示拼音码表，为“英”时显示英文码表。
- 操作按键切层时，微软拼音跟随切换；“双击切换”每次双击只切换一次并保留，“按住使用”按住进入中文、松开回英文。
- 显示／隐藏码表不改变输入层或微软拼音状态：“双击切换”用单击显隐，“按住使用”用双击显隐。

切回英文前，尚未确认的电码会先在原模式完成。微软拼音中尚未选字的内容会保留为原拼音字母：例如在“双击切换”中输入 `nihao` 后双击 F22 切英文，或在“按住使用”时松开 F22，保留的是 `nihao`，不会自动选中“你好”。需要中文时，先完成选字再切回英文。

切换使用原生输入法接口，不额外发送 Enter、Space 或 Shift，也不会替你更换系统输入法；使用前仍需在目标窗口选择微软拼音。软件会读取实际状态确认结果；窗口变化、访问权限不足、响应超时或切换未确认时会显示对应提示，不会将未知状态当作英文。切到其他窗口后不会把旧请求写到新窗口。可关闭同步，继续手动切层并使用其他拼音输入法。

## 显示码表

“双击切换”模式下单击 **F22** 显示／隐藏码表；“按住使用”模式下双击显隐。原 **Ctrl+Alt+Shift+M** 仍作为额外快捷键保留，在“启动与快捷键”中可修改或关闭；若它也设置为 F22，则统一由所选拼音层手势处理。快捷键不能与输入键重复，隐藏码表时输入继续运行。

码表顶部的“精简显示”将窗口收紧到键位区域，只保留按键及按键内文字、摩斯码，按键之间透明。按住键位区域内部拖动可移动窗口；拖动窗口边缘或角落可等比例调整大小，也可右键选择“调整大小”中的“放大”“缩小”或“默认大小”。比例自动保存，重新开启精简模式时沿用。

右键选择“完整显示”可恢复原来的完整窗口大小，托盘和设置也提供精简开关。鼠标对照默认隐藏，可独立开启。

“适应窗口”默认开启。关闭后，只有英文完整码表使用设置中的手动字号缩放，并可滚动查看；拼音码表和精简模式始终适应窗口。精简模式的整体大小通过拖动边缘或右键菜单调整。

完整和精简模式分别保存最后的位置。返回设置后重新开始、隐藏码表以及退出重启都能恢复；原显示器不再连接时会回到可见屏幕。

切换显示器、分辨率或 Windows 显示缩放后，文字尺寸与键位布局会自动重新计算，无需重启。精简模式保留手动缩放比例，在较小屏幕上临时缩小，空间足够时恢复保存的比例。已隐藏或最小化的窗口会保持原状态。

设置窗口会根据屏幕可用区域确定初始大小，窄窗口中的选项自动换行，内容仅纵向滚动；底部操作按钮保持可见。换屏或调整显示缩放后会适应可见范围，正常的手动窗口大小会保留。

完整和精简码表均置顶，显示、拖动、缩放和打开码表菜单时不会主动激活码表窗口。游戏建议使用无边框全屏或窗口模式；不能保证覆盖独占全屏画面。

## 托盘与开机自启

- 最小化按钮收到任务栏；× 隐藏到系统托盘，保持输入。点击托盘图标可恢复窗口。
- 托盘“启用输入”带勾表示正在接收输入；“退出”会关闭软件，释放监听、音频及程序按住的修饰键和鼠标键。
- 设置中的“开机自启，并收进系统托盘”立即生效。勾选“启动后默认收进系统托盘”后，平时打开也不弹出设置窗口。需要启动后直接接收输入时，再勾选“启动后自动开始输入”。

## 配置保存与恢复

改动设置会立即写入：先完整写入临时文件，再替换原配置；失败会保留原文件，并在设置页或托盘显示原因提示。可检查磁盘空间或文件权限后再次更改设置。

无效配置字段会单独使用默认值，其余有效偏好继续保留；整份文件无法解析时使用默认设置并记录日志。读取时不会因为异常覆盖原文件。安装版升级也不会用开发者配置覆盖你的设置。

更多输入、声音、组合键与手柄设置见 [完整使用说明](../README.markdown)。
