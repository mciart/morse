# 安装与使用

适用于 Windows 10 / 11 x64。从 [版本发布页](https://github.com/mciart/morse/releases/latest) 下载 `MorseWriter-Setup-v版本号-x64.exe`，按中文向导安装，无需另装 Python。程序默认安装到当前用户目录，配置保存在 `%LOCALAPPDATA%\MorseWriter\user_data`，升级保留偏好。

1. 打开设置，选择一到三个输入键。双键模式第一个键输入点，第二个键输入划；三键模式用第三个键确认字符。
2. 使用手柄映射时可选 F23 / F24，鼠标侧键可选 X1 / X2。点击“标准电键预设”可体验双键长按连发、15 WPM 的标准节奏。
3. 点击“开始输入”，切回目标应用。先在记事本练习 `E（•）` 与 `T（—）`。

统一码表包含 A–Z、0–9 和 18 个常用标点，国际电码已有定义的优先使用；其余标点采用常见扩展。反引号（\`）另用七个点 `•••••••`，位于数字行最左侧。旧版方案和分页布局已移除，升级后请留意标点及 F9、Delete、Tab、星号、百分号、修饰键锁定的编码变化，见 [完整码表](../codechart.md)。现有输入键、声音、主题和位置设置保留。

选定的点划输入键会被拦截；通过托盘取消“启用输入”即可暂停并恢复它们的普通用途。码表的“返回设置”也会停止输入。拼音层单键另用于切层和码表显隐。

## 输入拼音

先在目标应用中选择系统拼音输入法。设置的 **“拼音与码表切换”** 区域直接显示“按住使用”和“单击切换”两个选项，选择后点击“应用”。默认按住 **F22** 进入拼音层，松开恢复英文；选择“单击切换”后，单击切层，松开后保持。F22 可改为其他单个功能键（F1–F24，F12 除外），不能与点、划、确认键重复。

两种方式都支持快速双击 F22 显示／隐藏码表，双击只显隐，不切层。按住方式约 180 毫秒后才确认长按；按住期间开始输入点划会立即确认。单击方式短暂等待以区分双击，开始输入点划时也会立即确认。

声母显示在左侧、韵母在右侧。37 个注音电码直接输出相应拼音；复合韵母 `ing`、`uang` 等有独立扩展码，一次输出完整拼写。例如 `zh + ang → zhang`，再由系统输入法选字。`ü` 输出 `v`、`üe` 输出 `ve`、`ê` 输出 `e`；软件不自带中文候选系统。

Space、Enter、Esc、End、Insert 在拼音层使用不同编码，鼠标动作仍保留原码。请查看 [拼音码表](pinyin-code-chart.md)。

拼音层下方还提供 26 个符号，19 个沿用英文层编码，7 个因与拼音冲突而使用扩展码。它们按普通键盘符号输入，最终使用中文或英文标点取决于系统输入法的标点模式。

## 同步微软拼音

在“拼音与码表切换”中勾选 **“与微软拼音中／英文状态双向同步”**，再点击“应用”或“保存设置”。默认关闭；开启并开始输入后：

- 当前窗口的微软拼音为“中”时显示拼音码表，为“英”时显示英文码表。
- 操作按键切层时，微软拼音跟随切换；按住进入中文，松开回英文，单击切换则保持所选模式。
- 快速双击只显示／隐藏码表，不会让微软拼音快速切换两次。

松开时尚未确认的电码会先在原模式完成，再切回英文。**请先完成中文选字再松开**，软件不会自动按 Enter、Space 或提交候选。同步不会替你选择或更换系统输入法，使用前仍需在目标窗口选择微软拼音。

同步会读取实际状态确认切换；权限不允许、应用没有可用输入法或当前输入法身份不明确时会显示提示，不会将未知状态当作英文。切到其他窗口后不会把旧切换请求写到新窗口。可关闭同步，继续手动切层并使用其他拼音输入法。

## 显示码表

默认双击 **F22** 显示／隐藏码表，原 **Ctrl+Alt+Shift+M** 仍作为额外快捷键保留。在“启动与快捷键”中可修改或关闭额外快捷键；若它也设置为 F22，则统一由拼音层的按住／单击、双击手势处理。快捷键不能与输入键重复，隐藏码表时输入继续运行。

码表顶部的“精简显示”将窗口收紧到键位区域，只保留按键及按键内文字、摩斯码，按键之间透明。按住键位区域内部拖动可移动窗口；拖动窗口边缘或角落可等比例调整大小，也可右键选择“调整大小”中的“放大”“缩小”或“默认大小”。比例自动保存，重新开启精简模式时沿用。

右键选择“完整显示”可恢复原来的完整窗口大小，托盘和设置也提供精简开关。鼠标对照默认隐藏，可独立开启。

完整和精简模式分别保存最后的位置。返回设置后重新开始、隐藏码表以及退出重启都能恢复；原显示器不再连接时会回到可见屏幕。

切换显示器、分辨率或 Windows 显示缩放后，文字尺寸与键位布局会自动重新计算，无需重启。精简模式保留手动缩放比例，在较小屏幕上临时缩小，空间足够时恢复保存的比例。已隐藏或最小化的窗口会保持原状态。

设置窗口会根据屏幕可用区域确定初始大小，窄窗口中的选项自动换行，内容仅纵向滚动；底部操作按钮保持可见。换屏或调整显示缩放后会适应可见范围，正常的手动窗口大小会保留。

完整和精简码表均置顶，显示、拖动、缩放和打开码表菜单时不会主动激活码表窗口。游戏建议使用无边框全屏或窗口模式；不能保证覆盖独占全屏画面。

## 托盘与开机自启

- 最小化按钮收到任务栏；× 隐藏到系统托盘，保持输入。点击托盘图标可恢复窗口。
- 托盘“启用输入”带勾表示正在接收输入；“退出”会关闭软件并释放监听与修饰键。
- 设置中的“开机自启，并收进系统托盘”立即生效；需要开机后直接接收输入时，再开启并保存“启动后自动开始输入”。

更多输入、声音、组合键与手柄设置见 [完整使用说明](../README.markdown)。
