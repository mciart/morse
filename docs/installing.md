# 安装与首次使用

适用于 Windows 10 / 11 x64。从 [版本发布页](https://github.com/mciart/morse/releases/latest) 下载 `MorseWriter-Setup-v版本号-x64.exe`，按中文向导安装，无需另装 Python。程序默认安装到当前用户目录，配置保存在 `%LOCALAPPDATA%\MorseWriter\user_data`，升级保留偏好。

从浏览器下载的安装包尚未代码签名。Windows 可能显示“无法验证发布者”或 SmartScreen 拦截，这不表示文件被篡改。可打开“更多信息”后选择“仍要运行”，再用发布页中的 `SHA256SUMS` 核对下载文件。安装完成后若勾选运行，请在系统托盘（任务栏右下角，必要时点击 ^ 显示隐藏图标）查找摩斯输入。

1. 打开设置，选择一到三个输入键。双键模式第一个键输入点，第二个键输入划；三键模式用第三个键确认字符。
2. 使用手柄映射时可选 F23 / F24，鼠标侧键可选 X1 / X2。点击“标准电键预设”可体验双键长按连发、15 WPM 的标准节奏。
3. 点击“开始输入”，切回目标应用。先在记事本练习 `E（•）` 与 `T（—）`。

显示／隐藏码表和切换中英文层默认使用 **F22**（单击显隐、双击切层）。额外的全局显隐快捷键默认关闭，需要时再在设置的“高级：额外显隐快捷键”中开启。

源码运行沿用项目内的 `user_data/config.json`。仓库自带的旧配置为三键（1、2、Space）且静音，首次从源码启动也会使用这些值；与全新安装版的默认配置不同。需要声音时，在设置中勾选“播放摩斯音”。

完整的拼音层、微软拼音同步、精简码表、托盘、开机自启和配置说明见 [完整使用说明](../README.markdown)。码表见 [英文码表](../codechart.md) 与 [拼音码表](pinyin-code-chart.md)。
