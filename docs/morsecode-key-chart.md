# 摩斯码对照

请查看由软件映射自动生成的 [完整码表](../codechart.md)。此处不再维护旧版手抄表，避免文档与实际按键编码不一致。

`•` 表示点，`—` 表示划。默认码表使用美式键盘布局，可直接执行键盘与鼠标动作；鼠标对照默认隐藏，需要时开启。英文词语候选已移除。

默认编码方案为“国际摩斯优先”，包含 A–Z、0–9 和 18 个常用标点：已有国际定义的字符遵循 ITU 编码，其他标点采用常见扩展。反引号（\`）另以七个点 `•••••••` 补充，位于数字行最左侧。控制键和鼠标动作使用软件扩展码。

设置中可切回“旧版专用”。两个方案的标点和部分控制键编码不同，请查阅完整码表中的对应章节；旧编码不会同时作为默认方案的别名生效。

单次组合键先输入修饰键，再输入目标键，例如先 `Ctrl`、再 `V` 执行一次粘贴。需要连续组合键时，先启用“修饰键锁定”，结束后再次输入该编码释放修饰键。

虚拟码表支持自动缩放和透明精简显示。操作方法见 [安装与使用](installing.md)。
