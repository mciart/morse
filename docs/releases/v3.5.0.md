## 摩斯输入 3.5.0

适用于 Windows 10 / 11 x64。下载下方 `MorseWriter-Setup-v3.5.0-x64.exe` 安装即可使用，无需另装 Python。

### 新增与改进

- 开机自启选项，登录 Windows 后默认收进系统托盘；是否自动开始接收输入可独立设置。
- 全局快捷键 **Ctrl+Alt+Shift+M** 显示／隐藏码表，支持修改或关闭，隐藏时保持输入。
- 托盘“启用输入”菜单增加勾选状态，开启、暂停、恢复一目了然。
- 新用户界面主题默认跟随系统，保留深色／浅色可选项与原生标题栏适配。
- 修复最小化到任务栏、关闭到托盘和首点丢音，改善双键电键节奏、声音和视觉反馈。
- 支持 F13–F24 与鼠标 X1 / X2 输入，码表默认完整适应窗口，鼠标对照可选。
- 中文安装向导与当前用户安装，个人配置和学习词库与程序文件分离，升级保留偏好。

### 使用提示

设置中的“开机自启，并收进系统托盘”立即生效；如果还需要开机后直接输入，请开启并保存“启动后自动开始输入”。

按 Ctrl+Alt+Shift+M 可调出隐藏的窗口；托盘“启用输入”带勾时正在接收输入。声音关闭时可勾选“播放摩斯音”，或选择“标准电键预设”体验双键自动电键。

安装包附带 SHA256 校验文件，当前未进行代码签名。
