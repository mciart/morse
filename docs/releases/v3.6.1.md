## 摩斯输入 3.6.1

适用于 Windows 10 / 11 x64。下载 `MorseWriter-Setup-v3.6.1-x64.exe` 安装，无需另装 Python，升级保留个人设置。

### 修复与调整

- 修复 Windows 下从已显示的完整码表切换“精简显示”后，窗口可能消失的问题。
- 精简窗口支持拖动四条边或角落等比例调整大小；按住内部键位区域仍可移动窗口。
- 右键菜单新增“调整大小”，可选择“放大”“缩小”或“默认大小”。缩放比例自动保存，切换和重新启动后沿用。
- 调整大小时保持码表完整、窗口紧贴键位区域；返回完整显示时恢复此前的完整窗口大小。

### 使用方法

在完整码表顶部勾选“精简显示”。需要调整大小时，将鼠标移到窗口边缘或角落，出现缩放光标后拖动；也可使用右键菜单。右键选择“完整显示”即可返回。

安装包附带 SHA256 校验文件，当前未进行代码签名。
