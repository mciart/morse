## 摩斯输入 3.8.0

新增拼音输入层，适用于 Windows 10 / 11 x64。下载 `MorseWriter-Setup-v3.8.0-x64.exe` 安装，升级保留个人设置。

### 一个按键控制拼音层与码表

- 默认使用 F22，可在“启动与快捷键”中更换为其他独立功能键。
- **按住使用**：按住进入拼音层，松开恢复英文键盘。
- **单击切换**：单击切换拼音／英文，松开后保持；短暂等待以区分双击，开始输入点划时会立即确认单击。
- 两种方式均支持快速双击同一个键显示／隐藏码表。原来的额外显隐快捷键继续保留；设为同一个键时由上述手势统一处理。
- 当前电码固定使用开始输入时的层，松开或切换不会将未确认的拼音误解释为英文。暂停恢复、更换按键时清除旧状态。

### 声母与韵母码表

- 37 个基础符号沿用注音电码，键帽显示拼音；声母在左、韵母在右，底部保留数字和编辑键。
- 补齐完整复合韵母及 y / w 拼写字母。例如输入 `zh` 和 `ang` 即输出 `zhang`，使用系统拼音输入法选字。
- 按键盘拼音输入约定，ü、üe、ê 分别输出 v、ve、e。完整韵母一次输出，不自动改写已经输入的音节。
- 英文层原码保留；拼音层内发生冲突的编辑键使用独立编码。鼠标区域仍默认关闭，31 个鼠标动作保持原码。
- 完整与精简码表均支持切层，复用已缓存的键帽，保留窗口位置、大小、显隐状态和目标应用焦点。

使用前请在目标应用中启用系统拼音输入法；本软件输出拼音按键，选字由系统输入法完成。完整说明见 [README](https://github.com/mciart/morse/blob/v3.8.0/README.markdown) 和 [拼音码表](https://github.com/mciart/morse/blob/v3.8.0/docs/pinyin-code-chart.md)。
