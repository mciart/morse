## 摩斯输入 3.6.0

适用于 Windows 10 / 11 x64。下载 `MorseWriter-Setup-v3.6.0-x64.exe` 安装，无需另装 Python，升级保留个人设置。

### 新增与调整

- 快捷键设置可以直接选择 F13–F24，包括 F22，无需键盘上有对应按键；继续支持自定义组合键和关闭快捷键。
- 新增“精简显示”：窗口收紧到键位区域，只保留按键及按键内的文字和摩斯码，无标题栏、外部说明和外围空白，键位间隙透明。
- 精简模式支持拖动和右键恢复，托盘、设置及完整码表顶部的开关同步保存。
- 恢复码表保持置顶，不主动抢走目标应用焦点。游戏建议使用无边框全屏；独占全屏无法保证覆盖。
- 移除英文词语候选、后台预测和相应打包依赖，保留直接按键输出。
- 升级时保留软件中当前的开机自启选择，安装向导中的手动选择仍优先。
- 更新中文 README、安装说明、开发说明和自动生成码表，移除过时的英文操作说明。

### 使用提示

在设置的“启动与快捷键”中选择 F22，再点击“应用”。用于点、划的输入键请另选，例如 F23 / F24，避免冲突。

打开码表后，在顶部勾选“精简显示”。按住键位区域拖动窗口；右键恢复完整显示，或通过托盘菜单切换。鼠标对照仍默认关闭，可独立启用。

安装包附带 SHA256 校验文件，当前未进行代码签名。
