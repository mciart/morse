# 摩斯输入

用一到三个按键输入摩斯码，完成文字输入、键盘快捷键与鼠标操作。界面使用简体中文，码表按美式键盘布局排列，默认自动缩放并跟随系统主题。

默认按住 F22 使用拼音层，声母在左、韵母在右，也可设置为单击切换；双击同键显示／隐藏码表。拼音层沿用 37 个注音电码并补充完整韵母，输出拼音后由系统拼音输入法选字。

设置中的“拼音与码表切换”直接提供两种操作方式，也可开启与当前微软拼音中／英文状态的双向同步，默认关闭。快速双击只显隐，不会反复切换输入法。拼音码表下方包含 26 个符号，无需切回英文码表输入标点。

码表可切换为仅有键位区域的透明精简叠加层。鼠标对照默认关闭；软件不自带中文候选系统，旧英文预测功能已移除。
