# 摩斯输入

用一到三个按键输入摩斯码，完成文字输入、键盘快捷键与鼠标操作。界面使用简体中文，码表按美式键盘布局排列，默认自动缩放并跟随系统主题。

新用户默认单击 F22 显示／隐藏码表，双击切换中英文层；也可选择“按住使用”，按住拼音、松开英文、双击显隐。拼音层声母在左、韵母在右，沿用 37 个注音电码并补充完整韵母，输出拼音后由系统拼音输入法选字。

设置中的“拼音与码表切换”提供上述两种操作方式，也可开启与当前微软拼音中／英文状态的双向同步，默认关闭。显隐不改变输入法状态；“双击切换”每次双击只切换一次，不改变码表显隐。拼音码表下方包含 26 个符号，无需切回英文码表输入标点。

码表可切换为仅有键位区域的透明精简叠加层。鼠标对照默认关闭；软件不自带中文候选系统，旧英文预测功能已移除。

暂停、返回设置或退出会释放程序按住的修饰键和鼠标键。设置保存失败会显示提示并保留原文件；配置中的无效字段单独恢复默认，读取时不覆盖原文件。空闲界面反馈和静音音频片段已减少重复计算，输入节奏保持不变。
